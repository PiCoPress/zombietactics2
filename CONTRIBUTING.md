# Contributing to Zombie Tactics 2
Thank you for your interest in contributing to this mod! You can suggest any idea, report bugs, or open a pull request.

## Suggestions
If you have a good idea, feel free to share it on Github Discussions. I love empowering zombies.

## Bugs/Issues
Have you seen bugs or issues? Then it may be reported to Github Issues. Make sure to include a clear and detailed description.  
For example, if it crashed; attach crash reports too. Or if you found inefficient code, explain why and propose an alternative.

## Supporting other Minecraft versions
Currently, I'm maintaining versions 1.21.1, 1.21.4, 1.21.5. But it's hard to support other else versions since modder is not an occupation. Anyway I'll try to support more versions when possible... or you can contribute!

## Adding new config options
This mod requires midnightlib for Fabric, but midnightlib does not allow modifying its configuration prefix. As a result, the same prefix is used in the NeoForge as well, except for the tab title. 
When adding new config options, please follow the translation file format used in midnightlib to ensure consistency.
