# Contributing to Zombie Tactics 2
Thank you for your interest in contributing to Zombie Tactics 2! You can suggest any idea, report bugs, or open a pull request.

## Suggestions
If you have a good idea, feel free to share it on GitHub Discussions. I love empowering zombies.

## Bugs/Issues
Have you seen bugs or issues? If so, please report it to GitHub Issues. Make sure to include a clear and detailed description.  
For example, if a crash occurred, attach crash reports. If you find inefficient code, explain why and propose an alternative.

## Supporting other Minecraft versions
When a new version of Minecraft is released, support for non-major previous versions may be dropped. But you can fork the repository and add support for older versions.

## Adding new config options
This mod requires midnightlib for Fabric, but midnightlib does not allow modifying its configuration prefix. As a result, the same prefix is used in NeoForge as well, except for the tab title. 
When adding new config options, please follow the translation file format used in midnightlib to ensure consistency.
